SRAVANI BIRTHDAY PAGE – SOURCE
==============================
Open index.html in Chrome/Safari to run it (internet needed once for the fonts).

WHAT TO EDIT
- config.js   -> NAME, FROM, the LETTER lines, and the A-Z wishes.  (easiest place)
- index.html  -> page title, the "Hey <name>..." opening text, button/banner text.
- script.js   -> the step button names (search "const S=[") and the cake speech bubbles
                 (search "say(").
- style.css   -> colours, fonts, sizes, letter paper look.
- assets/     -> replace images/music with your own, keeping the same file names:
                 portrait.jpg (photo shown in the letter), cake.jpg, background.jpg,
                 music.mp3, balloon-*.png, light-*.png, banner.png

To share: upload the whole folder (or this zip) to any static host, or send the zip.
Keep index.html, config.js, script.js, style.css and the assets folder together.
